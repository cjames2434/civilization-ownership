    About the data

    Everything on this map comes live from free public web services run by government agencies. Nothing is bought and no API keys are used. When you click a piece of land, the site asks that area's official parcel service who owns it, then asks the deed or sales registry for its history.

    Why some places show more than others: land records in the U.S. are kept by about 3,100 county offices, and each state decides what goes online. Some publish every deed with buyers, sellers and prices. Some publish only the current owner. Some (Texas, for example) never disclose sale prices. Some (New Jersey, Maryland) remove owner names from open data for privacy. Where no free parcel data exists, the map still shows public land nationwide and links to the county's own records.
